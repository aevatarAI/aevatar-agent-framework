## Artifacts

### API Endpoints

#### POST /api/notebooks/{id}/cards:generate
- **Purpose:** Generate flashcards from notebook sources/context via CardsService and persist them under cards/ with stable ids.
- **Location:** learning/src/Aevatar.Learning.Api/Cards/CardsApi.cs
- **Request Format:** JSON: { topic: string, count?: number, providerName?: string, selectedSourceIds?: string[] }
- **Response Format:** JSON: { ok: true, count: number, cards: LearningCard[] }

#### GET /api/notebooks/{id}/cards:daily
- **Purpose:** Get the daily SRS queue (due + new) for a notebook with bounded defaults.
- **Location:** learning/src/Aevatar.Learning.Api/Cards/CardsApi.cs
- **Request Format:** Query params: maxDue (int, optional, default 20), maxNew (int, optional, default 20)
- **Response Format:** JSON: { ok: true, queue: CardsDailyQueue }

#### POST /api/notebooks/{id}/cards:review
- **Purpose:** Submit a review grade for a card, apply deterministic scheduling update, persist card state, append a review record (best-effort).
- **Location:** learning/src/Aevatar.Learning.Api/Cards/CardsApi.cs
- **Request Format:** JSON: { cardId: string, grade: number (0-5), generateMnemonic: boolean, providerName?: string }
- **Response Format:** JSON: { ok: true, result: CardsReviewResult }

#### GET /api/notebooks/{id}/cards:stats
- **Purpose:** Return notebook-scoped SRS stats (total/new/due/reviewedToday/totalReviews).
- **Location:** learning/src/Aevatar.Learning.Api/Cards/CardsApi.cs
- **Request Format:** No body.
- **Response Format:** JSON: { ok: true, stats: CardsStats }

### Integrations

#### Integration
- **Description:** Program.cs registers CardsService and maps CardsApi endpoints; endpoints resolve NotebookWorkspace via NotebookDirectoryStore and operate purely on the notebook directory (cards/ as source of truth).
- **Frontend Component:** learning/frontend (future cards UI)
- **Backend Endpoint:** POST/GET /api/notebooks/{id}/cards:*
- **Data Flow:** UI generates cards → API calls CardsService.GenerateAsync (LLM + context) → writes cards/{cardId}/card.json; UI fetches daily queue → API scans card state → returns due/new; UI submits review → API applies SM-2 update → writes card.json + appends reviews.jsonl → UI fetches stats.
