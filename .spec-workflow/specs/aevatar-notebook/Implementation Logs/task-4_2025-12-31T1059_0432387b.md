## Artifacts

### API Endpoints

#### POST /api/sources/text
- **Purpose:** Create a text source (paste) and index it via SourceIndexer (source entry + chunk entries, optional vector upserts).
- **Location:** notebook/Sources/SourceApi.cs
- **Request Format:** JSON: { text: string, title?: string, chunkingOptions?: { maxChunkChars?, overlapChars?, maxChunks?, boundaryBacktrackChars?, minChunkChars? } }
- **Response Format:** { ok: true, sourceId: string, memoryId: string, sourceEntryId: string, chunkCount: number, vectorUpsertCount: number }

#### POST /api/sources/file
- **Purpose:** Upload a .txt file (multipart/form-data) and index it via SourceIndexer with bounded size checks.
- **Location:** notebook/Sources/SourceApi.cs
- **Request Format:** multipart/form-data: file=<IFormFile> (only .txt, <= 1_000_000 bytes)
- **Response Format:** { ok: true, sourceId: string, memoryId: string, title: string, fileName: string, chunkCount: number, vectorUpsertCount: number }

#### GET /api/sources
- **Purpose:** List indexed sources (MemoryStore resources with memoryId prefix source::).
- **Location:** notebook/Sources/SourceApi.cs
- **Request Format:** None
- **Response Format:** { count: number, sources: { sourceId, memoryId, entryCount, latestAt }[] }

#### GET /api/sources/{sourceId}
- **Purpose:** Fetch recent entries for a source resource (debug-grade).
- **Location:** notebook/Sources/SourceApi.cs
- **Request Format:** Path param: sourceId
- **Response Format:** { sourceId, memoryId, count, entries: MemoryEntry[] }

### Integrations

#### Integration
- **Description:** SourceApi uses SourceIndexer to write sources/chunks to IMemoryStore and optionally vectors to IMemoryVectorIndex; downstream NotebookContextBuilder and NotebookAgent consume these resources.
- **Frontend Component:** notebook UI (left column)
- **Backend Endpoint:** POST /api/sources/text, POST /api/sources/file
- **Data Flow:** User adds source → SourceApi validates → SourceIndexer indexes → MemoryStore resources/chunks available for context builder and Q&A
