# Example Axioms (demo)

> 这是一个示例文件，用来验证“materials → multi-agent 推理”的闭环。
> 你可以删除或替换为真实公理/资料。

## A1. Basic algebra (demo)

- 对任意实数 \(a,b\)，有交换律：\(a+b=b+a\)，\(ab=ba\)
- 对任意实数 \(a,b,c\)，有结合律：\((a+b)+c=a+(b+c)\)，\((ab)c=a(bc)\)
- 分配律：\(a(b+c)=ab+ac\)

## A2. Probability (demo)

- 若事件 \(A,B\) 独立：\(P(A\cap B)=P(A)P(B)\)
