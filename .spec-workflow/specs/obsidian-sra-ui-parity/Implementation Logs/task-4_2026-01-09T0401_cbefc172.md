- **Description:** Web host now uses a thin wrapper (frontend/src/app/useAppController.ts) to inject WebTransport into shared useWorkbenchController; shared controller connects to AG-UI SSE via transport.connectAgUiEvents and performs REST calls via transport.info/listSessions/createSession/sendInput/uploadAttachments/getDeliverables/getJson/postJson.
- **Frontend Component:** scientific-research-assistant/frontend/src/app/useAppController.ts (wrapper) + scientific-research-assistant/ui/src/controller/useWorkbenchController.ts (core)
- **Backend Endpoint:** AG-UI SSE: GET /api/sessions/{id}/agui/events; REST: /api/info, /api/sessions, /api/sessions/{id}/input, /api/sessions/{id}/uploads, /api/sessions/{id}/deliverables, /api/sessions/{id}/tools, /api/sessions/{id}/goals, /api/sessions/{id}/dag, POST /api/sessions/{id}/mcp/reconnect, /api/skills/*
- **Data Flow:** UI mount → transport.info/listSessions → state; user connects session → transport.connectAgUiEvents → controller dispatches events into MessageStore + panel snapshots; user sends → uploadAttachments → sendInput → SSE updates UI
