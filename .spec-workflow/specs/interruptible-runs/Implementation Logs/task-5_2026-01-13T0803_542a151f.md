### Integrations

#### Integration
- **Description:** SRA /input -> BeginNewRun cancels previous RunContext, emits CUSTOM run_interrupted, runs executor under RunContextScope with run.Token; downstream AIGAgentBase and VibeOrchestrator observe CancellationToken and stop streaming/tool loops; UI reacts to CUSTOM events.
- **Frontend Component:** scientific-research-assistant/ui/src/controller/useWorkbenchController.ts
- **Backend Endpoint:** POST /api/sessions/{sessionId}/input
- **Data Flow:** New message -> backend cancels old run -> emits CUSTOM(run_interrupted) -> starts new run task -> executor uses run.Token -> cancellation stops streaming and closes message -> emits CUSTOM(run_canceled) + RUN_FINISHED(canceled=true) on cancel.
