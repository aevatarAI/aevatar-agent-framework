### API Endpoints

#### POST /api/notebooks/{id}/skills:generate
- **Purpose:** Generate a versioned agent skill bundle for a notebook via SkillsService and persist it under skills/{version}/.
- **Location:** learning/src/Aevatar.Learning.Api/Skills/SkillsApi.cs
- **Request Format:** JSON: { theme?: string, providerName?: string, selectedSourceIds?: string[] }
- **Response Format:** JSON: { ok: true, meta: SkillsBundleMeta, bundle: SkillsBundle }

#### GET /api/notebooks/{id}/skills
- **Purpose:** List skill bundle versions for a notebook by reading skills/*/meta.json (best-effort).
- **Location:** learning/src/Aevatar.Learning.Api/Skills/SkillsApi.cs
- **Request Format:** No body.
- **Response Format:** JSON: { ok: true, count: number, versions: SkillsBundleMeta[] }

#### GET /api/notebooks/{id}/skills/{version}
- **Purpose:** Get a specific skill bundle version (meta + structured bundle + markdown) from the notebook directory.
- **Location:** learning/src/Aevatar.Learning.Api/Skills/SkillsApi.cs
- **Request Format:** Path params: notebookId, version.
- **Response Format:** JSON: { ok: true, meta: SkillsBundleMeta, bundle: SkillsBundle, markdown: string }

### Integrations

#### Integration
- **Description:** Program.cs registers SkillsService and maps SkillsApi endpoints; endpoints resolve NotebookWorkspace via NotebookDirectoryStore and read/write versioned bundles under NotebookWorkspace.SkillsDir (directory-backed notebooks).
- **Frontend Component:** learning/frontend (future skills UI)
- **Backend Endpoint:** POST/GET /api/notebooks/{id}/skills*
- **Data Flow:** UI generates skills → API calls SkillsService.GenerateAsync (LLM + context) → writes skills/{version}/skill.json + skill.md + meta.json → UI lists versions → API reads meta.json files → UI fetches a version → API returns meta + bundle + markdown.
