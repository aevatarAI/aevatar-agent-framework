╚══════════════════════════════════════════════════════════════════════════════╝

【侦察门控 (scout_gate)】
  通过条件（满足其一）：
  ✓ 强接受：accept_count >= k 且 strong_refutation_count == 0
  ✓ 软接受 + HPA 稳定：
    • accept_count >= k-1
    • coherence >= min_coherence
    • gap_norm <= max_gap_norm
    • associator_mean <= max_associator_mean

【验证决策 (decide_promote)】
  ✓ proved = true  → 提升为定理
  ✗ proved = false → 进入 B 池选择

【停止条件 (stop_or_continue)】
  ✓ done == true
  ✓ iteration >= max_depth
  否则 → 递归继续


╔══════════════════════════════════════════════════════════════════════════════╗
║                          HPA 三元组应用                                       ║
╚══════════════════════════════════════════════════════════════════════════════╝

【Rotation (扫描 Θ)】
  位置：hpa_prepare 步骤
  作用：基于迭代次数和黄金比例计算扫描目标，避免共振
  公式：Θ = (iteration × α + seed_phase) mod 2π
       其中 α = φ⁻¹ ≈ 0.618

【Factorization (因子化)】
  位置：所有 LLM 步骤
  要求：每个假设必须包含
    • depends_on: 最小依赖集（公理/定理 ID）
    • factor_sequence: 有序推理路径
  作用：用于嵌入计算和关联子计算

【Projection (投影/间隙 δ)】
  位置：验证和评估步骤
  规则：
    • 不接受隐藏假设
    • 任何缺失的引理/假设必须明确声明为 gap_or_counterexample
    • 如果存在 gap，accept=false 或 proved=false


╔══════════════════════════════════════════════════════════════════════════════╗
║                          假设选择规则                                         ║
╚══════════════════════════════════════════════════════════════════════════════╝

所有假设选择都从 state.existing_hypothesis 中选取：

1. propose_hypothesis
   └─ 从 existing_hypothesis 选择 1 个假设 A
      • 不能是 seen_hypotheses 中的
      • 必须包含 depends_on 和 factor_sequence

2. propose_fallback_b_scout
   └─ 从 existing_hypothesis 选择 3-5 个备选 B
      • 解决 refutation 问题
      • 不能是 seen_hypotheses 中的

3. propose_fallback_b_verify_failed
   └─ 从 existing_hypothesis 选择 3-5 个备选 B
      • 解决验证失败的 gap δ
      • 不能是 seen_hypotheses 中的

4. propose_fallback_b_no_verify
   └─ 从 existing_hypothesis 选择 3-5 个备选 B
      • 解决不进入验证的问题
      • 不能是 seen_hypotheses 中的

║                          状态更新规则                                         ║
╚══════════════════════════════════════════════════════════════════════════════╝

【提升为定理时】
  • state.theorems.append(new_theorem)
  • state.iteration++
  • state.history.append(record)
  • state.current_hypothesis = null
  • state.seen_hypotheses.append(normalized_statement)

【选择新假设时】
  • state.current_hypothesis = selected_hypothesis
  • state.last_candidate = selected_hypothesis
  • state.seen_hypotheses.append(normalized_statement)

【失败时】
  • state.last_b_pool = b_candidates
  • state.last_judgement = judgement
  • state.seen_hypotheses.append(normalized_statement)
