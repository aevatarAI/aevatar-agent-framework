### Integrations

#### Integration
- **Description:** ApiKeyModal uses SraTransport getJson/postJson/deleteJson to call LLM+secrets endpoints and gates reveal/editing when transport.capabilities.revealApiKey/secretsEnabled are false (remote baseUrl).
- **Frontend Component:** scientific-research-assistant/ui/src/panels/apiKey/ApiKeyModal.tsx
- **Backend Endpoint:** GET /api/llm/providers; GET /api/llm/provider/{name}; GET /api/llm/api-key/{name}[?reveal=true]; POST /api/llm/api-key; DELETE /api/llm/api-key/{name}; GET /api/llm/test/{name}; GET /api/llm/models/{name}?limit=...; POST /api/secrets/set; POST /api/secrets/remove
- **Data Flow:** Open modal → listProvidersAsync → user selects provider → getProviderAsync + getApiKeyStatusAsync → (optional) reveal key → set endpoint/model overrides via /api/secrets/* → set/delete provider api key → test provider/fetch models → update provider list
