## Artifacts

### API Endpoints

#### POST /api/notebooks/{id}/quiz:generate
- **Purpose:** Generate a quiz from notebook sources/context via QuizService and persist it under quizzes/; returns a redacted quiz (no correct answers).
- **Location:** learning/src/Aevatar.Learning.Api/Quiz/QuizApi.cs
- **Request Format:** JSON: { topic: string, count?: number, strictGrading?: boolean, providerName?: string, selectedSourceIds?: string[] }
- **Response Format:** JSON: { ok: true, quiz: { quizId, topic, createdAt, strictGrading, sourceIds, questions: { questionId,type,prompt,options }[] } }

#### POST /api/notebooks/{id}/quiz:submit
- **Purpose:** Submit answers for a quizId; returns graded attempt with explanations and score.
- **Location:** learning/src/Aevatar.Learning.Api/Quiz/QuizApi.cs
- **Request Format:** JSON: { quizId: string, strictGrading?: boolean, providerName?: string, answers?: { questionId: string, answer: string }[] }
- **Response Format:** JSON: { ok: true, quizId: string, attempt: QuizAttempt }

#### GET /api/notebooks/{id}/quiz:history
- **Purpose:** List quiz history summaries for a notebook (best-effort).
- **Location:** learning/src/Aevatar.Learning.Api/Quiz/QuizApi.cs
- **Request Format:** Query params: max (int, optional, default 30).
- **Response Format:** JSON: { ok: true, count: number, items: QuizAttemptSummary[] }

### Integrations

#### Integration
- **Description:** Program.cs registers QuizService and maps QuizApi endpoints; endpoints resolve NotebookWorkspace via NotebookDirectoryStore (directory-backed notebooks).
- **Frontend Component:** learning/frontend (future quiz UI)
- **Backend Endpoint:** POST/GET /api/notebooks/{id}/quiz:*
- **Data Flow:** UI generates quiz → API calls QuizService.GenerateAsync → writes quizzes/{quizId}/quiz.json → returns redacted quiz; UI submits answers → API calls QuizService.SubmitAsync → appends attempts.jsonl and returns graded attempt; UI fetches history → API calls QuizService.ListHistoryAsync → returns summaries.
