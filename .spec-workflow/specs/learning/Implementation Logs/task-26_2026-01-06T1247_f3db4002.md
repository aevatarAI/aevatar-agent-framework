## Artifacts

### API Endpoints

#### POST /api/notebooks/{id}/reports:generate
- **Purpose:** Generate a new versioned report for a notebook using LearningReportService (LLM-backed) and persist it under reports/{reportId}/.
- **Location:** learning/src/Aevatar.Learning.Api/Reports/ReportsApi.cs
- **Request Format:** JSON: { topic: string, providerName?: string, selectedSourceIds?: string[] }
- **Response Format:** JSON: { ok: true, report: LearningReportMeta, preview: string }

#### GET /api/notebooks/{id}/reports
- **Purpose:** List existing reports for a notebook by reading reports/*/meta.json (best-effort).
- **Location:** learning/src/Aevatar.Learning.Api/Reports/ReportsApi.cs
- **Request Format:** No body.
- **Response Format:** JSON: { count: number, reports: LearningReportMeta[] }

#### GET /api/notebooks/{id}/reports/{reportId}
- **Purpose:** Get report meta + latest version content (v{CurrentVersion}.md) from the notebook directory.
- **Location:** learning/src/Aevatar.Learning.Api/Reports/ReportsApi.cs
- **Request Format:** Path params: notebookId, reportId.
- **Response Format:** JSON: { meta: LearningReportMeta, version: number, content: string }

### Integrations

#### Integration
- **Description:** Program.cs wires LearningReportService into DI and maps ReportsApi endpoints; reports are stored under NotebookWorkspace.ReportsDir so the notebook directory remains the system of record.
- **Frontend Component:** learning/frontend (future report UI)
- **Backend Endpoint:** POST/GET /api/notebooks/{id}/reports*
- **Data Flow:** UI generates report → API builds context + calls LLM → writes reports/{reportId}/v{n}.md + meta.json → UI lists reports → UI fetches report content.
