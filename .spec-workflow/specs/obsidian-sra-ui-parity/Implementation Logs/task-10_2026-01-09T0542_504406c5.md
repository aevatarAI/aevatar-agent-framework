### Integrations

#### Integration
- **Description:** GoalsPanel uses transport.putJson + transport.getJson against /api/sessions/{id}/goals; ComputePanel uses transport.postJson against /api/sessions/{id}/compute/decision; DagPanel uses transport.getJson against /api/sessions/{id}/dag and /dag/{nodeId}/explain. SraWorkbenchApp passes transport and wires DagPanel onOpenPage to route navigation (view=dag).
- **Frontend Component:** scientific-research-assistant/ui/src/panels/{GoalsPanel,DagPanel,ComputePanel}.tsx + scientific-research-assistant/ui/src/SraWorkbenchApp.tsx
- **Backend Endpoint:** PUT /api/sessions/{id}/goals; GET /api/sessions/{id}/goals; POST /api/sessions/{id}/compute/decision; GET /api/sessions/{id}/dag; GET /api/sessions/{id}/dag/{nodeId}/explain
- **Data Flow:** User edits goals → Save → transport.putJson → transport.getJson snapshot → onSaved updates controller state; User clicks refresh/explain in DAG → transport.getJson → state updates; User records compute decision → transport.postJson → onDecision updates controller state; User clicks Open DAG → SraWorkbenchApp navigate({view:'dag', session})
