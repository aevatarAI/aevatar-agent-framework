## Artifacts

### API Endpoints

#### POST /api/notebooks/{id}/sources/text
- **Purpose:** Import a text/markdown source into a notebook directory.
- **Location:** learning/src/Aevatar.Learning.Api/Sources/SourcesApi.cs
- **Request Format:** JSON: { title: string, content: string, mimeType?: string }
- **Response Format:** JSON: { ok: true, source: SourceMeta }

#### POST /api/notebooks/{id}/sources/file
- **Purpose:** Import a source file into a notebook (MVP: .txt/.md) via multipart/form-data.
- **Location:** learning/src/Aevatar.Learning.Api/Sources/SourcesApi.cs
- **Request Format:** multipart/form-data: file=<IFormFile>, optional field 'title'
- **Response Format:** JSON: { ok: true, source: SourceMeta }

#### GET /api/notebooks/{id}/sources
- **Purpose:** List sources in a notebook.
- **Location:** learning/src/Aevatar.Learning.Api/Sources/SourcesApi.cs
- **Request Format:** No body.
- **Response Format:** JSON: { count: number, sources: SourceMeta[] }

#### GET /api/notebooks/{id}/sources/{sourceId}
- **Purpose:** Get a source's metadata and bounded content from the notebook directory.
- **Location:** learning/src/Aevatar.Learning.Api/Sources/SourcesApi.cs
- **Request Format:** Path params: notebookId, sourceId.
- **Response Format:** JSON: { meta: SourceMeta, content: string }

### Integrations

#### Integration
- **Description:** Program.cs wires SourceStore into DI and maps SourcesApi endpoints; SourcesApi resolves NotebookWorkspace from NotebookDirectoryStore then delegates persistence/list/get to SourceStore.
- **Frontend Component:** learning/frontend (future sources UI)
- **Backend Endpoint:** POST/GET /api/notebooks/{id}/sources*
- **Data Flow:** UI imports text/file → API validates type/size → SourceStore writes sources/{sourceId}/meta.json+content → UI lists sources → UI fetches source content for context building.
